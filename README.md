# Site Biografia Princesa Diana

Criação de uma página biográfica sobre a Princesa Diana, como parte de uma atividade da disciplina de Desenvolvimento Web, em minha graduação em Engenharia de Software.

## Tecnologias utilizadas
- HTML
- CSS

## Principais Funcionalidades
- Navegação por menu com links internos para as principais seções da página.
- Seção inicial com apresentação da Princesa Diana.
- Uso de imagens para complementar o conteúdo biográfico.
- Rolagem suave entre as seções da página.
- Layout estilizado com HTML e CSS, utilizando cores, cards, imagens e organização visual do conteúdo.

## Seções
A página está organizada nas seguintes seções:
- Início
- Biografia
- Linha do Tempo
- Principais Feitos
- Falecimento

## Objetivo
Desenvolver uma página biográfica sobre a Princesa Diana, apresentando de forma organizada e visualmente atrativa informações sobre sua vida, trajetória, principais feitos e legado, utilizando HTML e CSS.
